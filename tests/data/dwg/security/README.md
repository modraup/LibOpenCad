# DWG password fixtures

These synthetic fixtures use source drawings generated by the repository. Their passwords are public test values.

- `AC1018.dwg` protects a three-LINE drawing from the native recovery fixtures. It uses the pinned Rust security test's `budweiser` password and 56-bit RC4 key derivation.
- `AC1021.dwg` protects the same three-LINE drawing with the password `Straßeı😀CaseMixCaseMixCaseMixCaseMixCaseMixCaseMix` and a 128-bit key. Stored handle pages and Reed–Solomon encoded object pages exercise both AC1021 read paths.
- `AC1032.dwg` protects the modeler fixture from `../modeler/AC1032.dwg`. It uses `budweiser` with a 40-bit key. The protected AcDs pages exercise SAB readback.

The fixture construction adds `AcDb:Security` with an independently generated verifier and encrypts the DWG section payloads page by page. The RC4 key is derived with Python's MD5 implementation from the full-uppercase UTF-16LE password. The native tests and pinned Rust revision `52034a673ff59bf6936ebf01ec794b07a97df246` both read the resulting files.

`metadata-AC1018.dwg` is a synthetic one-line R2004 drawing with both AppInfo and FileDepList descriptor flags set to 2 and no password protection. The metadata regression reads it, rewrites its preview, and reopens the geometry.
