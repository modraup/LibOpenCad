# DWG dynamic-block fixtures

Generated by `generate-dwg-dynamic tests/data/dynamic-properties-ascii.dxf tests/data/dwg/dynamic` using acadrust revision `52034a673ff59bf6936ebf01ec794b07a97df246` (MPL-2.0). The ASCII DXF source is this repository's dynamic-properties fixture; no third-party drawing is included.

Four versions (AC1021, AC1024, AC1027, AC1032) contain the enhanced-block evaluation graph, typed parameter/action/grip objects, seven INSERT/MINSERT variants and an anonymous paper-space representation. One INSERT stores a malformed one-point parameter cache. The pinned Rust DWG writer stores anonymous `BLOCK_HEADER` names as the bare prefix (`*U`); the numbered `*U1` name remains on the BLOCK marker.

Regenerate from the repository root:

```sh
cargo run --locked --manifest-path tests/upstream/Cargo.toml -- generate-dwg-dynamic \
    tests/data/dynamic-properties-ascii.dxf tests/data/dwg/dynamic
```

Native tests query saved properties, rewrite one linear parameter and reject empty-entity rewrites. Independent Rust readback checks the rewritten files.
