# DWG review regression fixtures

These R2004, R2007 and R2018 drawings are generated from the adjacent `modeler`
fixtures with acadrust commit `52034a673ff59bf6936ebf01ec794b07a97df246`.
The generator is `tests/upstream/src/dwg_review_regressions.rs`.

A 3DSOLID receives a `REVIEW_STRING` XRECORD in its extension dictionary. The
payload includes Chinese text, an empty string, literal string-handle fields
(5, 105, 320 and 329), a short integer, and a 330 object reference to the solid.
R2004 uses ANSI_936 (GBK), including the code-page byte in each native XRECORD
string; the modern controls use UTF-16. The files are test data generated by
Rust, without a Rust dependency in the native test executable.

Regenerate from the repository root before running native/Rust comparisons:

```sh
cargo run --locked --manifest-path tests/upstream/Cargo.toml -- generate-dwg-review tests/data/dwg tests/data/dwg/review
```

The native suite also uses the existing four-version `history/*.metadata.dwg`
fixtures for conflicting raw/stream XRECORD references and creates single-row
AcDs fixtures in memory. Invalid AcDs ownership/length cases use independent
native assertions because the pinned Rust reader shares that single-row bug.
Healthy copy/delete outputs, strings, object IDs and surviving history graphs
are read back by Rust.

## AcDs ownership and container boundaries

`AC1027-wide.dwg` and `AC1032-wide.dwg` are also generated by the same Rust
module. Each contains a box at the origin (dimensions 1, 2, 3) with handle
`0x10000000`, and a sphere centered at (10, 20, 30), radius 7, with handle
`0x110000000`. `wide-box.sab` and `wide-sphere.sab` are serialized directly
from the Rust writer's input entities, independently of the DWG reader.
The native test requires exact SAB equality for each owner before and after
an unchanged save. These fixtures detect truncation of an eight-byte owner
to four bytes without accepting the same defect in the upstream reader.

`tests/dwg_acds_integrity.cpp` constructs additional in-memory fixtures for
nested complete AcDs catalogs in length-prefixed SAB strings, real and fake
blob pages, unindexed trailers, corrupt segment directories and conflicting
owner records. It checks indexed and legacy storage, split SAB pages,
identical duplicates, per-owner diagnostics, neighbor preservation and
atomic refusal of edits to ambiguous geometry. These malformed/opaque cases
use independent assertions: Rust's current AcDs marker scanning and owner
truncation are known limitations, not correctness oracles.

## Legacy ViewRep

`viewrep-standard-legacy-AC1024.dwg` was generated with LibOpenCad before the
five-value R2010 ViewRep change. It starts from a blank R2010 drawing and
contains an `ACDBVIEWREPSTANDARD` at handle `0x10000000` with values 1 through
6, followed by a source manager. The native regression uses this file to
verify that editing and handle remapping preserve its sixth field.
