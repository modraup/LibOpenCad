# surface reference fixtures

Five specialized surface kinds with embedded LINE and ACIS body profiles, construction parameters and adjacent model/paper-space controls. R2007, R2010, R2013 and R2018, ASCII and binary DXF.

Generated by the test-only Rust oracle at acadrust `99d5f48800b1220f7a0a3f12fa46656cde995f3d` (MPL-2.0):

```sh
cargo run --locked --manifest-path tests/upstream/Cargo.toml -- generate-surface tests/data/surface
```

The native library has no Rust runtime dependency. Readback compares against the pinned source; these fixtures are not an independent CAD application validation.
