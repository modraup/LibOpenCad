# modeler-explode reference fixtures

Analytic and rational/trimmed spline boundaries plus solid/body/plane-surface face wires. R2010 and R2018, ASCII and binary DXF. The single-edge spline faces isolate parameter/reversal behavior and are not closed-solid validity fixtures.

Generated by the test-only Rust oracle at acadrust `99d5f48800b1220f7a0a3f12fa46656cde995f3d` (MPL-2.0):

```sh
cargo run --locked --manifest-path tests/upstream/Cargo.toml -- generate-modeler-explode tests/data/modeler-explode
```

The native library has no Rust runtime dependency. Readback compares against the pinned source; these fixtures are not an independent CAD application validation.
