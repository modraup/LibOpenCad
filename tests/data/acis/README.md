# ACIS test fixtures

Generated by `tests/upstream/src/acis.rs` using the pinned acadrust reference.

- SAT 400, 700 and 21800: seven primitive families and a closed planar tetrahedron.
- SAT 106: header without product/tolerance lines and explicit record indices.
- `multi-700.sat`: multiple roots, custom attribute text, signed zero and large/small coordinates.
- SAB companions: reference binary tags for modern SAT samples.
- `raw-22300.sab`: numeric widths, an int64 beyond f64 precision, UTF-8 and long strings, nested delimiters and coordinate tags.
- `legacy-600.sab`: a legacy point payload without the normalized pattern pointer.

The native tests read these inputs, independently construct the primitive topology,
edit placement, normalize versions and save outputs. The Rust verifier compares
typed values, record graphs and binary output. These standalone ACIS fixtures do
not establish DXF/DWG modeler-entity integration.

Regenerate with the upstream checker commands `generate-acis tests/data/acis` and
`generate-acis-sab tests/data/acis`.
