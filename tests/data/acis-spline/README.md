# acis-spline reference fixtures

Spline curves, UV curves, tensor-product and swept surfaces, shared definitions, offsets and legacy edge parameters. Each case contains SAT, SAB and R2010/R2018 ASCII/binary DXF.

Generated by the test-only Rust oracle at acadrust `99d5f48800b1220f7a0a3f12fa46656cde995f3d` (MPL-2.0):

```sh
cargo run --locked --manifest-path tests/upstream/Cargo.toml -- generate-acis-spline tests/data/acis-spline
```

The native library has no Rust runtime dependency. Readback compares against the pinned source; these fixtures are not an independent CAD application validation.
