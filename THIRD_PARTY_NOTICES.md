# Third-Party Notices

## acadrust

LibOpenCad is a native C++ port of selected functionality from
[acadrust](https://github.com/hakanaktt/acadrust), licensed under MPL-2.0.
The main Rust test reference revision is `52034a673ff59bf6936ebf01ec794b07a97df246` (acadrust 0.6.8).
The ACIS spline, DXF layout and multileader, and DWG ViewRep changes also draw on acadrust through `979fbde502c228325afeb907f8fffbcd15943337`.
The embedded DWG defaults retain their original `0c3ae80d` provenance.
Source comments identify the corresponding Rust modules; see [LICENSE](LICENSE).

The specialized DXF surface profile interfaces also follow acadrust's surface reader/writer, embedded-entity codec, and `io/loft_surface_curves.rs` metadata behavior. The curve and surface fixtures under `tests/data/surface-profiles` are generated with the Rust test oracle. Their native port and test sources retain MPL-2.0 notices.

The DWG port follows the acadrust bit streams, checksums, section codecs, object readers and writers, and pre-R13 entity stream traversal. The empty drawings embedded from `src/dwg_defaults` were generated with the pinned Rust writer. The test-only command `generate-dwg-blank <version> <path>` in `tests/upstream` generates defaults for the selected revision. The compound DWG regression fixtures are generated by `generate-dwg-compound <version> <path>` from the current reference source.

## ACadSharp

The DWG reader and writer include code ported and adapted from ACadSharp. The repository
history's initial DWG support commit identifies the source classes explicitly, including
`DwgStreamReaderBase`, `DwgLZ77AC21Decompressor`, `DwgFileHeaderWriterAC18`, and
`DwgObjectWriter`. Their current Rust implementations are in `src/io/dwg`.

## DWG Format References

The Open Design Alliance (ODA) DWG specification is the primary published reference for
the binary layouts documented by this project. Where the specification is incomplete or
ambiguous, implementation details are checked against native DWG files produced by CAD
applications. Source comments and regression tests identify the evidence used for each
layout and behavior. ACadSharp remains the attributed origin of the existing reader and
writer code described above.
